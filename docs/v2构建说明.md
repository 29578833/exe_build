# 汽修宝电脑版 v2（Win7 兼容版）构建说明

## 版本信息

- 版本号：2.0.0（对应安装包 QiXiuBaoInst_v2_win7.exe）
- 内核：NW.js 0.72.0（Chromium 108，Win7 x86/x64 兼容顶点，0.73+ 不再支持 Win7）
- 架构：32 位 x86（与原版一致，Win7 32 位系统可安装）
- 安装器：原版 NSIS 壳 + 品牌宣传图逐字节保留，只替换内嵌 RAR 数据
- 原版基准：QiXiuBaoInst.exe（2018-07-12 打包，md5 59fcdb7e49e393b10e0b428d98174bfb，官方至今未更新）

## 与旧版（1.0.0）核心差异

| 项目 | 旧版 | 新版 |
|------|------|------|
| 内核 | Chromium 50 (2016) | Chromium 108 (2022) |
| 框架 | NW.js 0.19 | NW.js 0.72.0 |
| Node | ~6.x | ~16.x |
| 安全 | 1000+ CVE 未修 | 修复至 2022-11 |
| 刷新按钮 | 正常 | inject_js_start 修复（ProcessSingleton 重启失效） |

## 文件说明

- `QiXiuBaoInst_v2_win7.exe` — 最终安装包（交付物，入库）
- `inject.js` — 刷新按钮修复脚本（注入渲染进程，见下）
- `patch_installer.py` — PE 补丁脚本（把新 RAR 嵌入 NSIS 壳 RES/132 资源）
- `newpack.rar` — 新内核 RAR 数据包（88MB 中间产物，不入库，可复现）

## 复现构建步骤

1. 下载 NW.js 0.72.0 32 位：
   `curl -L -o nwjs-v0.72.0-win-ia32.zip https://dl.node-webkit.org/v0.72.0/nwjs-v0.72.0-win-ia32.zip`
   （注意文件名是 win-ia32，不是 win-x86）

2. 组装 build/ 目录：0.72 runtime 全文件 + 原版 package.json（version 改 2.0.0 +
   inject_js_start 字段）+ 原版 app/（icon + node-main.js）+ inject.js + 原版 unins000.*
   + 0.72 的 nw.exe 改名为 汽修宝电脑版.exe
   - 移除：chromedriver.exe / dbghelp.dll / libexif.dll / natives_blob.bin /
     snapshot_blob.bin / .DS_Store（新内核不需要或垃圾文件）
   - 注意：新版内核用 v8_context_snapshot.bin 取代 natives_blob + snapshot_blob

3. RAR 打包（必须与原版同压缩级别 m3:22，否则 NSIS 内置解压器丢尾部文件）：
   ```
   Rar.exe a -ma3 -m3 -ep1 -x*.pak.info newpack.rar <小文件...>
   Rar.exe a -ma3 -m3 -ep1 -x*.pak.info newpack.rar *.exe
   Rar.exe a -r -ma3 -m3 -ep1 -x*.pak.info newpack.rar app
   Rar.exe a -r -ma3 -m3 -ep1 -x*.pak.info newpack.rar locales
   Rar.exe a -r -ma3 -m3 -ep1 -x*.pak.info newpack.rar swiftshader
   Rar.exe a -ma3 -m3 -ep1 newpack.rar nw.dll   # 大文件最后
   ```

4. 嵌入安装器：
   `python3 patch_installer.py`（改 SRC/NEW_RAR/OUT 三个常量）

5. 验证：7z 读新 exe 的 RAR（86+1 文件）、RES/132 Size == len(newrar)、
   startInstall_1.png 品牌资源仍在

## 刷新按钮修复（inject.js）

网页端刷新逻辑 = spawn 新进程 + hide + close + reload（重启式刷新）。
Chromium 108 的 ProcessSingleton 使新实例起不来 + 页面托盘逻辑拦截 close → 变最小化。
inject.js（package.json 顶层 inject_js_start 字段注入渲染进程）：
1. 劫持 child_process.spawn：自我重启只写 localStorage 标记，不真启动
2. 拦 close：标记存在时 preventDefault，阻止窗口被关/最小化
3. reload 后 show() 恢复窗口显示（页面先执行了 hide()）
